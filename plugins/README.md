# OpenCrawl integrations

The four desktop harness plugins are developed, tested and released from [opencrawl-plugins](https://github.com/getopencrawl/opencrawl-plugins). The CLI and Replicas setup consume the same immutable release inventory.

This directory contains the CLI's Devin Cloud export and managed skills under `opencrawl-sessions/`, and the HTTP MCP service's registry descriptor under `registry/`. See [release ownership](../docs/PLUGIN-RELEASE.md).
