# 0.6.0: incremental production baseline

This release reconciles the shared product runtime and UI to the deployed
`bcfe0643abdf` baseline while retaining PostgreSQL Better Auth, registry and board
from `3a17ce99a3c4`. Capture event identities remain in PostgreSQL. Independent
CLI, plugin and release tooling remain available.

The broad whole-application state migration, online migration machinery, new
connector lifecycle workflows and unfinished server onboarding rewrite are
removed. Hosted adoption uses one core package and keeps its current scoped SQL
namespaces and activation receipts. It does not replay historical data.

Privacy/deletion controls, credentials, onboarding receipts and indexing metadata
retain their established production storage contracts. Further PostgreSQL moves
are independent, tested domain changes and are not prerequisites for ordinary
feature delivery.

Self-host installations start from an empty PostgreSQL database: startup runs
`dist/src/state/initialize.mjs initialize` and then `verify` before writers
start. There is no upgrade or import from an earlier release; an installation on
an older version keeps that version or starts again from scratch. Removed
whole-state and new onboarding APIs are a breaking change from 0.5.
